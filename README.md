# hxwl-08 葡萄酒盲品训练

产区、品种与感官特征的盲品复习系统。

## 技术栈

React 19 + Vite + TypeScript + 原生 CSS，数据保存在浏览器 localStorage，无需后端。

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5108

## 功能说明

- **选产区出题**：6 个产区（波尔多、勃艮第、纳帕谷、里奥哈、阿尔萨斯、皮埃蒙特），共 20 张题卡。
- **先线索后答案**：出题阶段只露出颜色 / 酸度 / 单宁 / 酒体 / 酒精度与结构线索；作答后才揭晓产区、酒款、葡萄品种与典型香气。
- **四选一判分**：每题 4 个品种选项（红酒 / 白酒分别抽取干扰项，防止靠颜色猜），支持键盘 1-4 作答、回车继续。
- **复习队列（SRS 简化版）**：
  - 答对 → 题卡退出队列；
  - 第一次答错 → 插到队中第 3 位；
  - 第二次答错 → 第 2 位；
  - 第三次及以上 → 直接插到队首；
  - 错题必须再次答对才会退出队列，全部清空即完成本轮。
- **成绩记录**：答对数量、当前 / 最高连续答对、每个产区累计正确率，首页看板一目了然。
- **进度不丢**：队列、已掌握卡片、本轮得分、未关闭的揭晓答案、历史成绩全部实时写入 localStorage，关掉页面或刷新后可原样恢复；换产区会先二次确认。

## 目录结构

```
src/
  data/wines.ts          # 产区与题卡数据、选项生成（种子随机、跨设备稳定）
  lib/storage.ts         # 持久化状态、复习队列调度、统计派生
  lib/useStore.ts        # useSyncExternalStore 绑定
  components/Home.tsx    # 产区选择与成绩看板
  components/Trainer.tsx # 出题、作答、揭晓、完成页
```
